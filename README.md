
# Project Java PBO

Aplikasi desktop Catatan Kendaraan dengan fitur Login dan Register.

# Fitur
- Registrasi akun
- Login pengguna
- Validasi username dan password
- Konfirmasi password
- Penyimpanan akun menggunakan SQLite

# Teknologi
- Java
- Java Swing
- SQLite
- SQLite JDBC

# Struktur Project
- Main.java
- LoginForm.java
- Database.java
- lib/sqlite-jdbc-3.54.1.0.jar

# Cara Menjalankan
1. Buka project melalui Visual Studio Code.
2. Pastikan Java sudah terpasang.
3. Pastikan SQLite JDBC tersedia di folder lib.
4. Jalankan Main.java untuk registrasi.
5. Jalankan LoginForm.java untuk login.
